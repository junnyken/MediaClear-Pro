Quyết định phải giữ: **không đổi lịch sử**, không renumber, không xoá tài liệu đã publish.

## Goal

Cho mỗi MINI-SPEC một ID chuẩn duy nhất và tra ngược được, để không còn chỗ nào trong tài liệu hay
mã nguồn mà `MCP-10` có thể hiểu theo hai nghĩa.

## Constraints (Guardrails)

1. Không đổi tên, không sửa nội dung, không xoá file MINI-SPEC đã publish của Phase 0/Phase 1.
2. Canonical ID là **ổn định**; ID đã publish không được tái sử dụng cho tài liệu khác.
3. Historical ID không được xoá khỏi index.
4. Không có hai canonical ID trùng nhau.
5. MINI-SPEC mới **bắt buộc** có prefix phase (`P1.1-MCP-16` …).
6. Index phải kiểm được bằng test, không dựa vào việc con người nhớ cập nhật.

## Scope

**A. Domain model** — không đụng domain. Đây là lớp tài liệu.

**B. Services/engine** — không có service.

**C. API contract** — `API_ROUTES.mcp` chuyển từ `MCP-xx` / `MCP-xx-P1` sang canonical
`P0-MCP-xx` / `P1-MCP-xx`. Đây là **đổi tham chiếu**, không phải renumber tài liệu.

**D. UI surfaces** — không đổi.

**E. Tests** — test đọc `docs/MINI_SPEC_INDEX.md`: không trùng canonical ID, mọi file MINI-SPEC
trên đĩa đều có hàng trong index, mọi `API_ROUTES.mcp` đều là canonical ID có thật trong index.

**Gap** (vocabulary): một ID, hai nghĩa; ba quy ước; không có nguồn tra cứu.

## Design Choice

Tạo `docs/MINI_SPEC_INDEX.md` làm **nguồn tra cứu duy nhất**, ánh xạ
`canonical ID → historical ID → phase → tên → đường dẫn → trạng thái`. File lịch sử giữ nguyên tên;
canonical ID sống ở index và ở mã nguồn. Lý do chọn: đổi tên 17 file sẽ phá mọi đường dẫn đã trích
dẫn trong báo cáo đã publish, mà lợi ích chỉ là thẩm mỹ. Bỏ hướng "đổi tên file cho khớp" vì nó sửa
lịch sử — điều prompt cấm.

Mã nguồn chuyển sang canonical ID vì đó là tham chiếu đang chạy (và đang dùng quy ước thứ ba, sai cả
hai bộ), không phải tài liệu lịch sử.

## Test Plan

- Unit: index không có canonical ID trùng; mỗi canonical đúng định dạng `P<phase>-MCP-<nn>`.
- Integration: mọi file MINI-SPEC trên đĩa đều có mặt trong index (quét thư mục thật).
- Regression: mọi giá trị `API_ROUTES.mcp` phải tồn tại trong index (chặn tham chiếu mồ côi).
- Live: không áp dụng.

## Success Criteria

- Không còn canonical ID nào mơ hồ giữa các phase.
- Historical ID tra ngược được, không mất.
- MINI-SPEC mới không thể dùng ID thiếu prefix mà test vẫn xanh.

## Remaining Limits / Follow-ups

- File lịch sử vẫn mang tên cũ (`MCP-10.md` ở hai thư mục). Ai đọc thẳng tên file mà không qua index
  vẫn có thể nhầm — chấp nhận, đổi lại nghĩa là sửa lịch sử.
